# LED enclosure CAD

The project is committed to the **modular hinged direct-mount enclosure**
tracked by issue #133.

There is one supported mechanical architecture:

- fixed panel-side hinge template;
- universal moving hinge/base around a 6 mm metal rail;
- universal slide-in equipment backplane;
- detachable left/right side pieces;
- generic M3 adapter-boss grid for future PSU, MatrixPortal and other mounts.

The previous non-hinged backplanes, joiners, rear lids, desk stands and earlier
hinge prototypes have been removed rather than retained as alternate printable
designs.

The physically corrected P4 panel screw coordinates remain:

- X = **7.9 / 128.0 / 248.1 mm**
- Y = **7.9 / 120.1 mm**

See [`direct-mount/README.md`](direct-mount/README.md) for the canonical
printable parts, interface dimensions, validation process and physical test
sequence.
