# Support-free 6 mm hinge prototype v2

This is a deliberately simplified mechanical prototype for the LED direct-mount enclosure.

It exists alongside `hinge-version/`; it does **not** replace the verified production backplane or the earlier full equipment-enclosure experiment.

## Goal

Validate only these questions first:

1. Does the existing verified LED-panel mounting template still fit when a hinge is added?
2. Can a 6 mm metal rod pass through alternating fixed/moving knuckles?
3. Does the hinge open without the moving enclosure colliding with the fixed half?
4. Can both pieces be sliced without Bambu Studio reporting floating regions / floating cantilevers?
5. Does the fixed template provide a flat bottom tongue/sole so the hinge barrel does not protrude below the enclosure base?

## Key changes from the earlier hinge prototype

- The fixed side reuses `mount_pattern_template()` directly from `../direct_mount_enclosure.scad`.
- A full-width **8 mm-high × 18 mm-thick bottom tongue** is added to the template.
- The 14 mm hinge barrel is recessed behind that tongue rather than defining the lowest edge.
- Every fixed knuckle is hulled into bed-supported tongue material.
- Every moving knuckle is hulled into the enclosure's continuous lower wall.
- The moving enclosure is intentionally a plain constant-depth 24 mm box.
- The moving print is flipped **rear-face-down**, giving a print height of roughly **24.8 mm** instead of standing the 255 mm part vertically.
- No PSU mounts, taper, ventilation, cable slots or latch are included yet. Those should return only after the mechanical hinge is proven.

## Files

- `01_fixed_template_HINGE_TEST.scad` — fixed verified template + bottom tongue + fixed knuckles.
- `02_moving_enclosure_HINGE_TEST.scad` — shallow moving enclosure + complementary knuckles, already transformed for printing.
- `00_CLOSED_ASSEMBLY.scad` — closed assembly preview.
- `00_OPEN_ASSEMBLY.scad` — approximately 70° open assembly preview.
- `hinge_prototype_v2.scad` — source geometry.
- `stl/01_fixed_template_HINGE_TEST.stl` — generated printable fixed half.
- `stl/02_moving_enclosure_HINGE_TEST.stl` — generated printable moving half.

The SCAD files are the source of truth. The STL files are intentionally checked in for direct printing and are regenerated/compared by `Enclosure / Validate`; a PR fails if an STL is stale relative to its SCAD entrypoint.

## Hinge dimensions

- rod: **6.0 mm**
- bore: **7.2 mm**
- barrel OD: **14 mm**
- axis: **y=12 mm, z=9 mm**
- fixed bottom tongue: **8 mm high, 18 mm thick**
- nominal axial knuckle clearance: **1.0 mm**

## Printing

### Fixed template

Print exactly as generated, with the LED-facing template plane on the bed.

The bottom tongue is a continuous solid from Z=0, and the fixed barrels are hulled into it. No hinge cylinder should start as a disconnected or tangent-only region.

### Moving enclosure

Print exactly as generated by `02_moving_enclosure_HINGE_TEST.scad`.

The wrapper places the large flat rear plate directly on the build plate. The enclosure is therefore about 25 mm high during printing instead of about 255 mm high.

Supports should not be required for the prototype geometry.

## Test sequence

1. Slice both files in Bambu Studio before printing.
2. Confirm there are no floating-region/floating-cantilever warnings.
3. Print the fixed template first and verify the six panel holes and locator clearances against the real LED panel.
4. Print the moving enclosure.
5. Interleave the knuckles and insert the 6 mm rod.
6. Check free rotation and axial play.
7. Close the enclosure and place the assembly on its lower edge.
8. Confirm the tongue, not the hinge barrel, defines the base plane.
9. Only after this passes, migrate the proven hinge geometry back into the full equipment enclosure.

PETG is preferred for the hinge test; PLA is acceptable for a dimensional-only print.
